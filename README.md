# نظام الموازنة المزدوج — تطبيق ويب PWA

تطبيق ويب يعمل بدون إنترنت ويُثبَّت كتطبيق على الجوال.

## 📱 طرق الاستخدام

### الطريقة الأولى: ملف واحد محلي (الأبسط)

1. افتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome، Safari، Firefox، Edge)
2. التطبيق يعمل فوراً — كل المنطق داخل الملف
3. **يعمل بدون إنترنت** بمجرد فتحه

### الطريقة الثانية: تثبيت كتطبيق على الجوال (الأقوى)

لتمكين خاصية "إضافة إلى الشاشة الرئيسية" مع أيقونة كاملة، التطبيق يحتاج تشغيل عبر خادم HTTP. خياراتك:

#### أ) نشر مجاني على GitHub Pages / Netlify / Vercel
- ارفع الملفين (`index.html` + `sw.js`) إلى مستودع GitHub
- فعّل GitHub Pages من إعدادات المستودع
- افتح الرابط من جوالك → اضغط "إضافة إلى الشاشة الرئيسية"

#### ب) خادم محلي للاختبار
```bash
cd path/to/folder
python3 -m http.server 8000
# افتح http://localhost:8000 من نفس الشبكة الواي فاي
```

#### ج) رفع على أي خادم ويب لديك
ضع الملفين في أي مجلد على موقعك. هذا كل شيء.

## 🚀 التثبيت على الجوال

### Android (Chrome / Edge / Samsung Internet):
- افتح الرابط
- ستظهر لك خانة "تثبيت" أعلى التطبيق
- أو: قائمة المتصفح ⋮ → "إضافة إلى الشاشة الرئيسية" / "تثبيت التطبيق"

### iPhone / iPad (Safari):
- افتح الرابط في **Safari** (مهم - ليس Chrome)
- اضغط زر المشاركة 􀈂
- اختر "إضافة إلى الشاشة الرئيسية"

بعد التثبيت يفتح التطبيق بدون شريط متصفح، مثل أي تطبيق أصلي.

## 💾 ميزات تعمل بدون إنترنت

- ✅ تحليل الرسائل النصية بالكامل
- ✅ موازنة المخزون بين فرعين
- ✅ توليد مذكّرة النقل
- ✅ نسخ المذكّرة إلى الحافظة
- ✅ مشاركة المذكّرة عبر WhatsApp/SMS مباشرة
- ✅ تصدير CSV (يفتح في Excel)

## 🎨 الفرق بين هذا الإصدار وإصدار سطح المكتب

| الميزة | سطح المكتب | PWA |
|---|---|---|
| التشغيل | يحتاج Python + PySide6 | متصفح فقط |
| التثبيت | معقد | فتح ملف واحد |
| الجوال | لا | نعم — كتطبيق كامل |
| Excel | xlsx مع تنسيق | CSV (مفتوح في Excel) |
| PDF | نعم | لا (استخدم "طباعة → PDF") |
| العمل بدون إنترنت | محلي تماماً | محلي تماماً |
| المنطق | متطابق 100% | متطابق 100% |

## 📂 الملفات

- `index.html` — التطبيق كاملاً (HTML + CSS + JS + Manifest + الأيقونات)
- `sw.js` — Service Worker لتشغيل التطبيق بدون إنترنت

## 🖨 إذا احتجت PDF

من المتصفح: اضغط Ctrl+P (أو Cmd+P) → اختر "حفظ بصيغة PDF". الجداول تُطبع جيداً.
